This page exists to exercise `TsSandbox` while it is being built. It stays a draft, so it renders in `astro dev` and is left out of the production build.

Both editors start from the same source. `TimerState` includes `cancelled`, but the `switch` in `transition` never handles it, so the assignment to `never` fails with TS2322. Add `case 'cancelled': return state;` in one editor and only that editor's error should clear. Reset restores the original source, and the error with it.
