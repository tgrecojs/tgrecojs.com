## What is RAG?

Retrieval-augmented generation (RAG) starts with a search. When you ask a question, the application looks for a few relevant passages and sends them to a language model along with your question. The model uses that material to write an answer. If you keep track of where the passages came from, you can give the reader links to check the answer for themselves.

This is useful when the answer depends on a particular document or changes over time. If I ask what supply-chain risks Apple disclosed in fiscal 2025, I want to see what Apple said in that year's filing and have a way to read the relevant section myself.

For this demo, I'm starting with two short summaries from Apple's FY2025 10-K. I'll run the search on its own first so we can see which summary it picks up. Then I'll pass the retrieved evidence to a local model and look at the answer and its citations.
